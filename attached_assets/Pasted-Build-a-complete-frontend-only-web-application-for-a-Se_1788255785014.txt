Build a complete frontend-only web application for a **Secure Online Voting System** using **React + Vite + JavaScript**.

This is a college-level full-stack mini project. For now, build ONLY the frontend with dummy/mock data. Do not create or implement a backend, database, authentication server, Aadhaar verification, biometric verification, or real voting infrastructure yet. The frontend must be structured so that a Node.js + Express + MySQL backend can be connected later through REST APIs.

## PROJECT GOAL

Create a professional, modern, trustworthy online voting platform where voters can:

* Register and log in
* View available elections
* View candidate information
* Cast one vote in an active election
* Receive a voting confirmation
* See their voting status

Administrators can:

* Log in
* View an admin dashboard
* Create and manage elections
* Manage candidates
* View registered voters
* View voting statistics
* View election results

The design should feel like a modern civic/government digital service, but NOT copy any specific government website.

## DESIGN STYLE

Use a clean, professional, trustworthy visual language.

Design direction:

* Modern government/civic technology platform
* Minimal and spacious
* Professional typography
* Excellent visual hierarchy
* Subtle rounded corners
* Clean cards
* Soft shadows
* Accessible contrast
* Responsive design
* Desktop-first but fully responsive on tablet and mobile
* Avoid excessive gradients
* Avoid excessive animations
* Avoid a flashy startup/SaaS aesthetic
* Avoid overly colorful UI
* Avoid childish design

Use a restrained color palette based around:

* Deep navy / dark blue
* White
* Light gray
* Subtle blue accents
* Green only for success states
* Red only for errors/warnings

The interface should communicate:
**Trust + Security + Simplicity + Transparency**
